# Chube Hotend Integration

Owner-authored adaptation of the A4T UHF Rapido cowling using the Chube integration STEP as a dimensional reference. The edited files are labeled Chube Air UHF for CW2/Tap. This project is separate from A4T and A4Tv2 upstream.

| Folder | Contents |
| --- | --- |
| CAD (local `CAD/`) | Editable Chube Air UHF cowling STEP |
| STL (local `STL/`) | Printable Chube Air UHF cowling mesh |
| Prints (local `Prints/`) | Cowling 3MF and hexagon cowling 3MF |
| Reference (local `Reference/`) | Original `CHUBE_INTEGRATION_REVA.step` |
| Documentation (local `Documentation/Chube_hotend_integration_specifications.pdf`) | Chube integration drawing, Rev A, credited to Luke Ashley; associated model is `CHUBE_INTEGRATION_REVA.STEP` |

Upstream base: [Armchair Heavy Industries A4T](https://github.com/Armchair-Heavy-Industries/A4T), Dragon-Rapido UHF cowling family. The exact base revision and variant used for the edit are unconfirmed. Retain upstream license and reference notices; no redistribution rights are inferred for the Chube reference files. CAD clearance, slicing, and physical fit were not checked in this import.

# R3 K2 print plates

The revised face and bow sliced in PrusaSlicer 2.9.7 with the K2 0.4 mm presets and Polymaker ASA. Both print face-up with a 0.12 mm layer height and no support. The four-color face uses the same aligned part origins as the CAD assembly. Wipe tower and slicer priming are disabled.

| R3 plate | Physical CFS slots | Slicer estimate |
| --- | --- | --- |
| [Castle star face](K2_04_ASA_Castle_R3_Star_Face.3mf) | A purple, B gold, C cream, D blue | 3 h 42 min |
| [Rounded pink bow](K2_04_ASA_Castle_R3_Pink_Bow.3mf) | A pink | 41 min |

Use the existing [rear pocket](../K2_04_ASA_Castle_Reader_Pocket.3mf), [threaded grip](../K2_04_ASA_Castle_Threaded_Grip.3mf) and [card and thread coupon](../K2_04_ASA_Castle_Card_Loading_Coupon.3mf) plates for this revision. The corresponding production STL files have identical hashes across R2 and R3. Load the intended physical spool in each slot before starting a plate.

The [preflight report](preflight.json) records the verified four tools, first-layer extrusion, K2 macros, gold curl buildup and cream rose paths. The rose spiral and castle openings are inherited from R2. Physical fit, reader performance and the finish of the rounded layers still need a print.

# R5 K2 print plates

R5 clears the doorway beneath Mickey and follows the latest reference for the bow and paired gold curls. Both revised plates sliced in PrusaSlicer 2.9.7 using the K2 0.4 mm presets, the Polymaker ASA starting profile and 0.12 mm layers. Both print face-up without support. The face parts preserve their shared CAD coordinates, and the wipe tower and slicer priming are disabled.

# Small-arm adapter for the 40 mm clamp

This 54 × 54 × 9 mm plate connects an 18 × 18 mm small-arm holder to a 40 × 40 mm clamp. The outer pattern uses Ø5.6 mm through holes. The inner pattern uses Ø4.5 mm through holes with Ø8.2 mm counterbores 4.5 mm deep on the clamp face. The STL places the holder face on the build plate.

- [CadQuery generator](build_adapter.py)
- [STEP model](Small_Arm_18x18_to_Clamp_40x40.step)
- [Printable STL](Small_Arm_18x18_to_Clamp_40x40.stl)

Run `python build_adapter.py` from this directory in a CadQuery environment to regenerate both exports.

**Physical assembly fit is pending.** Check the adapter with the actual clamp, holder, and fasteners.

The mating clamp and small-arm system were designed by RostaP. [Multifunction Arm mounting system on Printables](https://www.printables.com/model/165239-multifunction-arm-mounting-system?lang=en)

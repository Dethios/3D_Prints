# Star Wars download sources

The model files and assembled print plates are in the local workspace. The candidate listings below identify designs to compare against the local files. Exact source archives were unavailable for a hash comparison.

The download channel, exact mesh and Thingiverse terms are unverified. [Printables](https://www.printables.com/model/868656-may-the-fourth-be-with-you-sign) · [Thingiverse](https://www.thingiverse.com/thing:6608558) · [Indexed description and license](https://www.stlfinder.com/model/may-the-fourth-be-with-you-sign/3667098) |

[MakerWorld](https://makerworld.com/en/models/2666928-lightsaber-birthday-candle-holder) · [Indexed listing](https://www.stlfinder.com/model/lightsaber-birthday-candle-holder-free-3d-print-model/6937519) |

[Head and Shoulders](https://www.thingiverse.com/thing:4309563) · [More Darth Vader Dice Towers](https://www.thingiverse.com/thing:3499898) |

Heref's indexed Head and Shoulders description specifies a full-size tower about 158 mm high and suggests a 70° Cura support angle to keep support out of the dice path. These settings describe the linked tower. The local plates may contain scaled or rearranged meshes. [Indexed maker instructions](https://www.stlfinder.com/model/darth-vader-dice-tower-head-and-shoulders/5568749)

The sign listing describes it as desk decoration. No slicer settings were verified. The candle-holder index gives no maker instructions.
